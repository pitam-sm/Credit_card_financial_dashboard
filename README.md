# Credit Card Performance Overview

This dashboard provides an interactive overview of credit card transactions and customer behavior. It helps analyze overall transaction performance, revenue generation, customer activity, and spending patterns across different segments.

### Key Business Metrics

* Total Revenue
* Total Transaction Amount
* Total Transactions
* Total Customers
* Average Transaction Value

### Key Insights

The dashboard enables analysis of transaction trends over time, customer spending behavior, card usage, and performance across different customer segments. It can be used to identify high-value customers, understand spending patterns, and monitor overall credit card business performance.

### Objective

The objective of this dashboard is to convert raw credit card transaction data into clear and actionable business insights that can support better decision-making and customer-focused strategies.
